# NoteMate – AI-Powered Study Assistant

NoteMate is an AI-powered study assistant designed to make learning easier and more interactive. It transforms uploaded study notes into useful learning resources using Google's Gemini AI.
🚀 **[Try NoteMate Live](https://notemate-qkmbzzvpu2nfr2qexdngvq.streamlit.app/)**

## Features

- **AI Summaries:** Generate concise summaries from uploaded notes.
- **Smart Flashcards:** Create interactive flashcards to improve revision.
- **AI Quiz:** Generate quizzes and receive flexible AI-based answer evaluation.
- **AI Assistant:** Ask questions and get explanations based on your notes.
- **Study Progress:** Track your learning activity.

## Technologies Used

- Python
- Streamlit
- Google Gemini AI
- PDFPlumber
- Python-DOCX
  
## Installation

1. Clone this repository.
2. Install dependencies:

   `pip install -r requirements.txt`

3. Create a `.env` file in the project folder and add your Gemini API key:

   `GEMINI_API_KEY=your_api_key_here`

4. Run the application:

   `streamlit run Ctf.py`

## Note

A valid Gemini API key is required to use the AI features.
